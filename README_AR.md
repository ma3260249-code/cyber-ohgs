# AORNLASO — الكون الرقمي المفتوح
## حزمة النواة الأولية 0.1

هذه الحزمة هي بداية تقنية قابلة للتطوير، وليست إطلاقاً إنتاجياً للعالم.

### محتويات الحزمة
- `apps/web`: واجهة Three.js + Vite + TypeScript.
- `apps/server`: خادم Colyseus مستقل عن جهة الاستضافة.
- `docs/ROADMAP_0.1.md`: نطاق الإصدار واختبارات القبول.
- `.gitignore`: استثناء الملفات والأسرار المحلية.

### المتطلبات
- Android مع Termux حديث.
- Node.js LTS وGit.
- اتصال إنترنت لتنزيل الاعتماديات.

### 1) تجهيز Termux
نفّذ الأوامر التالية داخل Termux:

```bash
pkg update && pkg upgrade -y
pkg install nodejs-lts git unzip -y
node -v
npm -v
```

### 2) فك الحزمة والدخول للمجلد
إذا كان الملف في مجلد Downloads:

```bash
termux-setup-storage
cd ~/storage/downloads
unzip AORNLASO_0.1.zip
cd AORNLASO_0.1
```

إذا حفظت الملف في مكان آخر، غيّر المسار وفق مكانه.

### 3) تشغيل خادم اللعب
افتح جلسة Termux أولى:

```bash
cd ~/storage/downloads/AORNLASO_0.1/apps/server
npm install
npm run dev
```

المتوقع أن يستمع الخادم على المنفذ `2567`.
اختبار الصحة بعد التشغيل:

```bash
curl http://127.0.0.1:2567/health
```

يجب أن يعيد JSON بحالة `ok`.

### 4) تشغيل الواجهة
افتح جلسة Termux ثانية:

```bash
cd ~/storage/downloads/AORNLASO_0.1/apps/web
npm install
npm run dev -- --host 0.0.0.0
```

افتح عنوان Vite الذي يظهر في الطرفية، وغالباً:
`http://127.0.0.1:5173`

### 5) اختبار لاعبين على جهازين
- الاختبار الأول على الهاتف نفسه يثبت تشغيل الواجهة والخادم محلياً فقط.
- لكي يتصل جهاز ثانٍ، يجب أن يكون قادراً على الوصول إلى عنوان الخادم عبر الشبكة.
- لا تستخدم `127.0.0.1` في الجهاز الثاني؛ فهذا العنوان يشير إلى الجهاز الثاني نفسه.
- لاختبار الإنترنت من شبكتين مختلفتين، انشر خادم Colyseus على استضافة عامة لاحقاً، ثم ضع عنوانه في `VITE_COLYSEUS_URL`.
- لا تفتح منافذ هاتفك للإنترنت ولا تشارك عنواناً عاماً قبل إعداد HTTPS/WSS والحماية.

### 6) ربط Supabase لاحقاً
أنشئ مشروع Supabase عندما نصل إلى مرحلة الحسابات الدائمة. انسخ:
- Project URL
- Publishable/anon key

إلى `apps/web/.env.local` اعتماداً على `.env.example`.
لا تضع `service_role` أو أي مفتاح سري داخل الواجهة أو GitHub.

### 7) GitHub
بعد مراجعة الملفات:

```bash
git init
git add .
git commit -m "AORNLASO 0.1 foundation"
```

أنشئ مستودعاً فارغاً في GitHub، ثم استخدم أوامر `git remote add origin ...` و`git push` التي يعرضها GitHub.
