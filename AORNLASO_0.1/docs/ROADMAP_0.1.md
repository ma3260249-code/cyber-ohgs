# AORNLASO 0.1 — خطة التأسيس

## نطاق هذه الحزمة
1. مشهد فضائي ثلاثي الأبعاد أولي.
2. خادم Colyseus authoritative وغرفة `world`.
3. إنشاء كيان لاعب عند الاتصال وحذفه عند المغادرة.
4. إرسال مدخلات الحركة إلى الخادم والتحقق من حدودها.
5. عرض اللاعبين المتصلين في الواجهة.

## ما لم يدخل بعد
- مصادقة Supabase الفعلية.
- حفظ دائم لملفات اللاعبين.
- توليد المجرات والكواكب إجرائياً.
- نظام سفن أو بناء أو اقتصاد.
- استضافة إنتاجية أو توزيع أفقي للخادم.

## اختبارات القبول
- [ ] يعمل الخادم ويستجيب لمسار `/health`.
- [ ] تفتح واجهة Three.js دون أخطاء.
- [ ] يتصل عميل واحد بغرفة `world`.
- [ ] يظهر عميلان في الغرفة نفسها.
- [ ] يرى كل عميل حركة الآخر.
- [ ] تُرفض قيم الحركة غير الرقمية أو الخارجة عن الحدود.
- [ ] يؤدي مغادرة العميل إلى إزالة مجسمه من الطرف الآخر.

## معيار الانتقال
لا نعلن اكتمال 0.1 قبل تشغيل الخادم على عنوان يمكن لجهازين الوصول إليه واجتياز الاختبارات أعلاه.
